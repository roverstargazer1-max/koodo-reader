## 验收前置准备

在进行各项测试前，建议启动应用并打开调试工具：
1. **启动应用**：运行开发服务器或启动 Electron 客户端。
2. **调出开发者工具 (F12)**：
   - 切换到 **Network (网络)** 面板；
   - 在 Filter 搜索过滤框中输入 `koodo` 或 `api.`；
   - 勾选 **Preserve log (保留日志)**；
3. **全局验收指标**：
   - 全程测试中，**Network 面板中不得出现任何指向 `api.koodoreader.com` 或 `api.koodoreader.cn` 的 HTTP/WebSocket/SSE 请求**；
   - 界面中**不存在任何 `(Pro)` 视觉角标、试用倒计时胶囊、购买专业版提示或跳转定价页的外链**。

## 二、数据同步与存储驱动

原版提供官方加密云库同步，并集成了 10 余种第三方商业网盘。本次重构清除了商业网盘与官方同步，保留纯自建协议与本地存储，并免鉴权完全开放。

### 2.1 验收测试项

| 编号 | 功能/模块 | 原版行为 | 当前本地化行为 | 测试验收操作步骤 | 预期结果 | 验收状态 |
| :---: | :--- | :--- | :--- | :--- | :--- | :---: |
| **B-1** | 官方云同步开关 | 设置提供“启用 Koodo 云同步 (Enable Koodo Sync)”，阅读数据上传至官方中心云 | 配置项与逻辑已彻底剔除 | 打开【设置 - 同步与备份】，向下滚动查看开关列表 | 不存在“启用 Koodo 云同步”开关 | [ ] |
| **B-2** | 商业网盘接入 | 支持绑定 OneDrive、Google Drive、Dropbox、阿里云盘、115网盘、Box、MEGA、Yandex 等 | 商业网盘全部从列表移除，避免未知的云端隐私传输 | 点击【添加数据源】，查看下拉列表与网格 | 仅保留：`WebDAV`、`S3 Compatible`、`Docker`、`FTP`、`SFTP`、`Local folder (本地文件夹)` | [ ] |
| **B-3** | 自建协议免 Pro 解锁 | WebDAV、S3、Docker、FTP、SFTP 均标有 `(Pro)` 红色角标，非会员配置被弹窗拦截 | 移除所有 `(Pro)` 标识，所有用户开箱免鉴权直接使用 | 点击添加 WebDAV 或 S3 存储 | 表单直接展开，无任何“请升级 Pro”弹窗阻断，可正常保存配置并校验连接 | [ ] |
| **B-4** | 本地文件夹备份与恢复 | 备份或恢复书库时选择本地文件夹，免费版会被提示“请升级至专业版”拦截 | 无条件完全开放本地备份与恢复能力 | 在【备份书库】与【恢复书库】下拉中选择 Local | 正常触发本地文件选择器，能够正常导出 `.zip` 备份或还原书库 | [ ] |
| **B-5** | 顶部同步触发按钮 | 点击 Header 的【同步】图标时，若未购买 Pro 则强制弹窗引导购买 | 移除拦截；未配数据源提示去设置，配置后触发真实自建同步 | 点击顶部右侧【同步】按钮 | 不再弹出“升级到专业版”警告；在未配置数据源时提示前往设置，配置后执行同步 | [ ] |

## 三、AI 服务与全文/划词翻译

原版将翻译与 AI 助读作为商业 Pro 核心权益，通过官方代理服务器转发并限制调用额度。本次重构移除了所有 Pro 限制，切断了向官方服务器的请求，并打桩预留了自定义直连通道。

### 3.1 验收测试项

| 编号 | 功能/模块 | 原版行为 | 当前本地化行为 | 测试验收操作步骤 | 预期结果 | 验收状态 |
| :---: | :--- | :--- | :--- | :--- | :--- | :---: |
| **C-1** | 全文双语/译文翻译 | 阅读器页面设置中的“全文翻译”选项带有 `(Pro)` 红色字样，切换时强制拦截 | 移除 `(Pro)` 标识，无拦截，可自由切换模式；源码打桩待接批量 API | 打开任意书籍 -> 打开右侧/呼出控制栏【设置】-> 找到【全文翻译】下拉 | 无 `(Pro)` 字样；可自由在“关”、“双语”、“仅译文”间切换，不弹付费阻断 | [ ] |
| **C-2** | 全文批量拉取请求 | 开启全文翻译翻页时，调用 `getBatchTrans` 向 `api.koodoreader.com` 批量发送文本段落 | 切断官方请求，本地返回空数组，无网络泄露 | 开启全文翻译模式并翻动章节，观察 Network 面板 | 不向 `api.koodoreader.com` 发出任何请求 | [ ] |
| **C-3** | 划词翻译插件 | 划词菜单的翻译 Tab 中，官方 AI 翻译插件标有 `(Pro)`，切换时拦截非会员 | 移除 `(Pro)` 标识与切换拦截，切断官方请求；未配置个人 API 弹出友好引导 | 选中文字呼出浮窗 -> 切换到【翻译】Tab -> 点击选择翻译插件 | 插件名无 `(Pro)` 后缀；切换不弹出购买提示；Network 面板无官方请求 | [ ] |
